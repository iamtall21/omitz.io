Privacy

Last updated November 9, 2026.

This website is a set of static pages. It has no forms, and fonts and images are served from this site. The only third-party code is the LinkedIn Insight Tag, described below.

LinkedIn Insight Tag

Omitz advertises on LinkedIn and uses the LinkedIn Insight Tag to measure those ads. When you visit, the tag sends LinkedIn information such as the page address, the page that referred you, your IP address, browser and device details and a timestamp, and it may set cookies. LinkedIn uses this to report to Omitz which ads led to visits and to show Omitz ads to past visitors on LinkedIn. Omitz receives only aggregated reports and cannot see who you are. LinkedIn’s handling of this data is covered by the LinkedIn Privacy Policy and LinkedIn Cookie Policy.

To opt out:

  • Turn on Global Privacy Control in your browser. This site then does not load the tag.
  • Turn off ads based on data from others in your LinkedIn advertising settings.
  • Block or delete third-party cookies in your browser settings.

Omitz does not sell personal information or use any other analytics or advertising tools on this site.

Hosting

The site is hosted on GitHub Pages. Like any web host, GitHub may record technical information such as your IP address in server logs for security and operations. See the GitHub Privacy Statement.

Contacting Omitz

If you email Omitz or message Phil on LinkedIn, the information you send is used only to respond to you and arrange training. It is not sold or shared for marketing.
